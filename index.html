Ambulanzbetrieb

Dieser Bereich umfasst wiederkehrende Abläufe rund um die Ambulanz, von der Vorbereitung bis zur Nachbereitung.

Vorbereitung der Ambulanz

Wählen Sie, ob es sich um Kontrollpatienten oder neue Patienten handelt:

Vorbereitung für Kontrollpatienten

  1. Holen Sie die entsprechenden Akten im Schlaflabor (Raum +2/31190).
  2. Tragen Sie den aktuellen BMI in das Formular ein (Größe und Gewicht prüfen).
  3. Füllen Sie den Epworth-Score (ESS) aus bzw. übernehmen Sie die Werte.
  4. Tragen Sie den AHI-Wert aus dem aktuellen Befund ein.

Vorbereitung für neue Patient:innen

  1. Bereiten Sie drei Blätter für neue Patienten vor.
  2. Legen Sie zusätzlich eine Folie bzw. Klarsichthülle bereit.
  3. Ordnen Sie die Blätter in der richtigen Reihenfolge.
  4. Legen Sie das Set zusammen mit der Patientenakte für die Sprechstunde bereit.

Wochenstart

Führen Sie diese Schritte jeweils zu Beginn der Woche durch:

Patientenverwaltung

Dieser Bereich enthält Anleitungen zur Patientendatenverwaltung in Orbis und MS Access sowie zur Terminvergabe für verschiedene Untersuchungs- und Kontrollformen.

Patientendatenverwaltung

Anmeldung bei ORBIS

In diesem Abschnitt wird beschrieben, wie der Einstieg in ORBIS erfolgt und welcher Bereich für die administrativen Abläufe im Schlaflabor ausgewählt wird.

  1. Öffnen Sie zunächst ORBIS auf dem Arbeitsplatzrechner.
  2. Melden Sie sich mit den persönlichen Zugangsdaten an.
  3. Wählen Sie im Menü den Bereich Pneumologie Ambulanz aus.
  4. Prüfen Sie, ob der richtige Arbeitsbereich geöffnet wurde.

Terminvergabe

Terminvergabe für neue Patienten ambulant und CPAP-Kontrolle

In diesem Abschnitt wird die Terminvergabe für neue ambulante Patienten sowie für CPAP-Kontrollen beschrieben.

  1. Öffnen Sie den Terminkalender in MS Access bzw. im entsprechenden System.
  2. Prüfen Sie verfügbare Termine gemäß Vorgabe.
  3. Tragen Sie den Termin ein und ergänzen Sie relevante Hinweise.
  4. Kontrollieren Sie die Eingabe abschließend.

Terminvergabe für CPAP-Kontrollen

In diesem Abschnitt wird die Terminvergabe für CPAP-Kontrollen mithilfe von MS Access und ORBIS beschrieben.

  1. Öffnen Sie zunächst MS Access.
  2. Erfassen bzw. kontrollieren Sie die relevanten Patientendaten.
  3. Wechseln Sie anschließend zu ORBIS.
  4. Öffnen Sie den entsprechenden Terminbereich für CPAP-Kontrollen.
  5. Prüfen Sie verfügbare freie Termine.
  6. Tragen Sie den ausgewählten Termin im System ein.
  7. Kontrollieren Sie die Eingabe abschließend.

Terminbestätigung

In diesem Abschnitt wird die Terminbestätigung beschrieben.

  1. Öffnen Sie zunächst MS Access.
  2. Suchen Sie die betreffende Patientin bzw. den betreffenden Patienten mithilfe der PID oder des Geburtsdatums.
  3. Prüfen Sie die hinterlegten Termindaten.
  4. Bestätigen Sie den entsprechenden Termin im System.
  5. Kontrollieren Sie abschließend die aktualisierten Informationen.
Hinweis: Hier können Hinweise zu Versand, Ausdruck oder telefonischer Rückmeldung ergänzt werden.

Büro & Material

Dieser Bereich bündelt organisatorische Tätigkeiten im Büro, die Materialversorgung sowie den Versand von Unterlagen.

Akten sortieren & archivieren

Das Einsammeln und Sortieren der Akten erfolgt vor allem nach der Sprechstunde. Durch den digitalen Ablauf (PG-Befund direkt im System) ist nur noch wenig Aktenablage im Archiv nötig.

Schritt 1: Akten einsammeln und sortieren

  1. Sammeln Sie alle verwendeten Patientenakten ein.
  2. Sortieren Sie die Akten (z. B. nach Datum oder Name).

Schritt 2: Unterlagen von Ebene +2 abholen

Holen Sie die benötigten Unterlagen von Ebene +2 herunter. Da der PG-Befund direkt im System hinterlegt wird, entfällt das frühere Kopieren der Akten.

Schritt 3: Restliche Akten ablegen

Nur wenige Akten müssen noch ins Archiv. Legen Sie diese sortiert an der vorgesehenen Stelle ab; der Großteil wird nicht mehr archiviert.

Büromaterialversorgung

Kontrollieren Sie regelmäßig, ob folgende Materialien im Büro ausreichend vorhanden sind. Falls etwas fehlt, holen Sie Nachschub im Raum Versorgung AWT.

Briefe & Befunde versenden

1. Arztbriefe abholen

Holen Sie die von Ihrer Kollegin fertig geschriebenen und ausgedruckten Arztbriefe ab.

2. Passenden Umschlag auswählen

Wählen Sie je nach Seitenanzahl den passenden Umschlag:

  • 1–2 Seiten: kleiner Umschlag
  • 3–4 Seiten: mittlerer Umschlag
  • ≥ 5 Seiten: großer Umschlag

Falten Sie die Briefe entsprechend und legen Sie sie in den ausgewählten Umschlag. Achten Sie darauf, dass Adressfeld und Absender korrekt sichtbar sind.

3. Versand vorbereiten und zur Post bringen

Sammeln Sie alle fertigen Umschläge und bringen Sie die Briefe anschließend zur Poststelle im Gebäude.
